## 🎨 Customization Guide

### Update Product Information
Edit the `productImages` array in `src/pages/index.astro`

### Update Testimonials
Edit the `testimonials` array in `src/pages/index.astro`

### Update FAQs
Edit the `faqs` array in `src/pages/index.astro`

### Update Process Steps
Edit the `processSteps` array in `src/pages/index.astro`

### Customize Colors
Update CSS variables in `src/layouts/Layout.astro`:
```css
:root {
  --color-cream: #F5F1ED;
  --color-wood: #6B5B47;
  --color-gold: #D4A574;
  /* etc */
}
```
